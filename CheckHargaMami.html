🔑 Setup API Key (sekali saja)

App ini butuh Anthropic API Key untuk membaca struk dan cek harga.
Key disimpan di HP kamu saja (tidak dikirim ke mana-mana selain Anthropic).

Cara dapat API Key gratis:
1. Buka console.anthropic.com
2. Daftar / login
3. Klik API Keys → Create Key
4. Copy key yang dimulai dengan sk-ant-...
